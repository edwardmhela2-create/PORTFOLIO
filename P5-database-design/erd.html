Maelezo ya muundo:
• PK (Primary Key) = kitambulisho cha kipekee kwa kila safu (kama namba ya NIDA).
• FK (Foreign Key) = kitambulisho cha jedwali lingine — ndicho kinachounganisha tables (uhusiano).
• CHECK = ulinzi wa ndani: database yenyewe inakataa kiasi hasi, riba > 100, n.k. (hata kama programu imekosea!).
• VIEW deni_halisi = "dirisha" linaloonyesha deni bila kuandika SQL kila mara.
• INDEX = kamashifuti wa vitabu — maswali yanakimbia haraka.
