# Muhtasari wa Portfolio (P9–P12)

## Mielelezo (P9) — Spam Predictor
- Data: sms.csv yenye mifano 74 (Kiswahili na Kiingereza).
- Mbinu: TF-IDF (ngram 1–2) + Multinomial Naive Bayes.
- Ufaulu: **94.7%** accuracy kwenye seti ya mtihani (25%).
- Udhahifu: False Positive (Type I) = ujumbe halisi kuchukuliwa kama
  spam — hasara ni kupoteza kuaminika.
